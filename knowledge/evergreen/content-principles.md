# 콘텐츠 원칙 (evergreen)

모든 초안이 따라야 하는 편집 기준입니다. 에이전트 프롬프트와 함께 RAG에 색인됩니다.

## 무엇을 쓰는가

1. **바뀐 것**만 쓴다. 요약이 아니라 delta(버전, 수치, 기한, 기본값, 제약)를 쓴다.
2. 독자가 **행동을 바꿀 수 있는 정보**를 우선한다: 마이그레이션, breaking change,
   가격, 한도, 강제 업그레이드 기한.
3. 1차 출처(공식 발표, GitHub release, 논문)를 근거로 한다. SNS/커뮤니티 글 하나만을
   근거로 글을 쓰지 않는다.

## 무엇을 쓰지 않는가

- 검증되지 않은 수치. 확인이 안 되면 문장을 빼거나 "확인 필요"를 명시한다.
- 과장 표현(혁명적, 게임체인저, 역사상 최초), 클릭 유도 문구.
- 투자 판단, 가격 전망.
- 출처의 마케팅 문구를 그대로 옮기는 문장.
- 벤더 간 우열 비교(원문이 비교한 경우만 인용).

## 형식

- 제목: 무엇이 바뀌었는지 한 줄.
- 본문: 바뀐 점 → 왜 중요한가 → 구체적 수치/버전 → 다음에 볼 것.
- 모든 항목에 원문 링크.
- 한국어 기본, 기술 용어는 영어 그대로(rollup, inference, breaking change).
- 해시태그는 주제 태그만, 채널별 상한 이내.

## 검수 기준 (review.md 에 자동 반영)

- `[차단]`: 1차 출처 미확인, 선별 항목에 없는 링크, 글자 수 초과, 출처 누락
- `[확인]`: 검증 실패 문장, 과장 표현, 수정 제안, 과거 콘텐츠와 유사
- `[참고]`: 숫자 재확인 목록, 원문이 답하지 않은 항목, 중복으로 제외된 항목
