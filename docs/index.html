AI 카드뉴스 자동화 시스템

뉴스를 모으고, 카드로 만들고, 인스타그램에 올리는 일까지 사람 없이.

RAG로 모은 사실을 AI가 글로 쓰고, 코드가 근거를 확인하고 디자인해서 매주 두 번 올립니다. 이 페이지는 그 공장이 실제로 어떻게 돌아가는지 보여 줍니다.

공정

소식 하나가 카드가 되기까지, 여섯 공정

공정마다 맡은 쪽이 다릅니다. AI는 글을 쓰고, 판단과 디자인과 안전은 코드가 맡습니다.

기획, 작성, 편집

3

근거 추적과 자동 수정

문장마다 근거가 있는지 대조하고, 근거가 약한 문장은 근거가 지지하는 범위로 좁혀 다시 씁니다. 새 숫자나 URL은 코드가 거절합니다.독립 심사관 AI가 제목 과장과 슬라이드 간 불일치를 한 번 더 찾습니다.

    역할 분담
    
      
    AI는 글을, 코드는 보증을
    
    
    
    
    
      
    
        
    AI 가 하는 일
    
        
      
          
    • 글쓰기장마다 제목과 본문, 캡션. 독자는 전문가가 아니라 관심 있는 일반 독자로 둡니다.
      • 
          
    • 쉬운 말로 풀기제목과 캡션에서 영어 전문용어와 코드 이름을 풀어 씁니다.
      • 
          
    • 근거 대조와 심사문장이 근거에 있는지 판정하고, 제목이 본문보다 넓게 말하지 않는지 봅니다.
      • 
          
    • 다시 쓰기문제로 지목된 문장만 근거 범위로 좁힙니다.
      • 
        
    
      
    
      
    
        
    코드 가 하는 일
    
        
      
          
    • 레이아웃 선택항목이 2~4개이고 순서가 있으면 번호 카드, 날짜가 3개 이상이면 타임라인, 마지막 장은 체크 박스.
      • 
          
    • 색과 가독성카테고리별 색을 쓰되 글자와 배경의 대비를 WCAG 기준(4.5:1)으로 계산해 맞춥니다.
      • 
          
    • 숫자 강조본문에서 단위가 붙은 숫자를 찾아 크게 보여 주고, 본문에 없는 숫자는 막습니다.
      • 
          
    • 승인과 게시 판단모델의 말이 아니라 검사 결과로 승인하고, 게시 직전 조건을 다시 점검합니다.
      • 
        
    
      
    
    
    
    
    AI는 틀릴 수 있습니다. 틀려도 밖으로 새지 않게 코드가 막습니다.
    
  
    

  
    
    
    
      
    틀린 말 막기
    
      
    실제로 잡힌 문장들
    
      
    아래는 이 시스템이 게시 전에 실제로 고치거나 막은 사례입니다. 사람이 읽고 고친 것이 아닙니다.
    
    
    
    
    
      
    
        
    근거 추적 → 자동 수정
    
        
    AI의 첫 문장CPU 구동 on-device TTS 3종 추가
    
        
    고친 문장Pocket TTS, CPU에서 실시간보다 빠르게 구동근거에서 CPU 구동이 확인된 모델은 하나뿐이었습니다.
    
      
    
      
    
        
    제목 쉬운 말 규칙
    
        
    AI의 첫 제목Flint의 MoE 라우팅 구조
    
        
    고친 제목Flint, 토큰마다 256개 중 6개만 골라 처리
    
      
    
      
    
        
    독립 심사관 → 자동 수정
    
        
    AI의 첫 제목CPU에서 도는 음성 모델 3종
    
        
    고친 제목CPU에서도 도는 음성 모델개수 단정을 근거가 지지하는 범위로 좁혔습니다.
    
      
    
      
    
        
    자동 게이트 → 게시 보류
    
        
    차단된 후보출처 10개 중 9개가 주제와 무관
    
        
    원인과 조치기사 페이지의 메뉴 링크가 출처로 올라오던 엔진 버그를 찾아 고쳤습니다.같은 후보의 발효일도 다른 출처와 달라 게시하지 않았습니다.

    고치면서 알게 된 것
    
      
    독립 심사관 AI가 "문제 없음"이라고 쓰면서 심각도를 high로 표시하는 일이 반복됐습니다. 프롬프트만으로는 막을 수 없어서, 심각도를 모델이 아니라 코드가 이슈 종류로 정하고 카드에 없는 문구를 인용한 지적은 버리도록 바꿨습니다.
    
    
    
  
    

  
    
    
    
      
    무인 운영
    
      
    매주 월요일에 모으고, 수요일과 일요일에 올립니다
    
    
    
    
    
      
    월
    08:30
    엔진이 최신 소식을 수집하고 검증해 이번 주 주제 2개를 정하고 알립니다.
    
      
    수
    08:30
    1번 주제로 카드를 만들고, 승인되면 게시합니다. 보류되면 예비 주제로 넘어갑니다.
    
      
    일
    08:30
    수요일에 쓴 주제는 건너뛰고 2번 주제로 같은 과정을 반복합니다.
    
    
    
    
    
      
    일시정지 파일
    파일 하나를 만들면 즉시 게시가 멈춥니다. 카드 생성과 승인은 계속됩니다.
    
      
    하루 게시 상한
    같은 날 한 건만 올립니다. 오류가 반복돼도 연속 게시되지 않습니다.
    
      
    토큰 자동 갱신
    인스타그램 토큰을 주 1회 갱신하고, 갱신본은 비밀 설정 파일 밖에 저장합니다.
    
      
    API 접근 사전 점검
    카드를 만들기 전에 접근 권한을 확인해서, 막혀 있으면 비용을 쓰지 않고 알립니다.
    
      
    다음 주제로 대체
    승인이 안 나면 같은 실행에서 예비 주제를 최대 3번까지 시도합니다.
    
      
    중복 방지와 신선도
    최근 후보가 있는 주제와 8일 넘은 수집 결과는 쓰지 않습니다.
